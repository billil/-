# 大学生群消息查找与使用需求调查问卷

群忆项目需求调研  共 8 题  预计用时 2—3 分钟

同学你好！我们想了解大家查找校园群消息的真实经历，以及是否需要新的辅助工具。本问卷自愿填写，不收集姓名、学号、联系方式或聊天截图，结果用于学生项目需求分析。请按实际情况作答，没有困难或暂时不需要工具同样是有价值的反馈。

填写说明：本问卷共 8 道选择题，可跳过不愿回答的问题。多选题请遵守题目中的数量限制；“没有”“未查找”“暂时不需要”等排他选项不要与其他选项同时选择。
