# 群访问申请授权核心（未上线）

这是独立开发中的 SQLite 原型。包含群管理员登记、申请、按群审核、授权查询和撤销，以及接入账户网关的本地测试版本。新增 `group_access_ui.html`、CSS 和 JS，提供独立的申请、消息与管理员审核页面。`authorized_reader.py` 按授权过滤机器人消息，`isolated_search.py` 在临时隔离数据库上调用现有后端查询并核验引用。测试使用打包的后端快照和模拟模型，不连接 DeepSeek。解压后运行 `python -m unittest discover -s . -p 'test_*.py' -v`。

本代码已在隔离环境接入测试网关登录会话，真实本地 HTTP 串联申请、审批、列表、搜索和撤权；隔离检索测试验证了模型仅收到获授权消息、不可引用其他群、权限变化时阻止返回。尚未接入线上网站、QQ 机器人、消息接口或真实 AI，不提供线上数据隔离，不能直接上线。共享消息入口默认关闭，测试仅在隔离进程中注入测试数据和模拟模型。bootstrap 只能由可信运维在核验机器人群标识、管理员身份后调用；不能由公开注册用户自行指定管理员。客户端提交的群号、账号或自称身份均不能作为认证。

隔离检索每次均为新话题，不保留会话；最多处理 1000 条消息，超过则明确报错，尚未实现分页索引。搜索过程中如已将候选发送给模型，之后撤权无法收回已发送内容；代码会在模型调用前后检查授权，变化则拒绝返回。临时数据库涉及数据生命周期，生产化前须完善存储及清理。

后续需在实际线上版本完成按群访问控制：列表、详情、检索候选、模型输入、来源引用、通知、缓存和撤权后的会话均须覆盖；账号 ID 必须从服务端登录会话取得；群标识必须映射官方机器人 group_openid。管理员需在线下核实申请人身份和群成员资格；机器人离群和用户退群需撤销或重新核验。需新增网页交互、真实 QQ 消息和跨账号、跨群、撤权测试后才能上线。线上网关与此测试网关的源文件哈希不一致，不能直接覆盖。
