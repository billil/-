# 群管理员自主认领：能力验证阶段

目标：群主或管理员将 QQ 官方机器人添加到新群后，可以在群忆认领该群，无需网站总管理员。目前没有实现或开放自动授权。

## 2026-11-05 实测

- 新增 QQ 机器人入群事件中观察到操作人标识非空。
- 另一轮中，同一测试QQ先添加机器人到新群，再向机器人私聊测试文本；一次样本中入群操作人标识与私聊标识逐字相同。
- 测试结果为单次观察，不代表所有账号、群、机器人应用或未来平台版本都具备同样的身份语义，也不证明网站账号、QQ账号及群主角色已绑定。
- 仅在进程内短时保留加密摘要；测试结束后已恢复原机器人代码并重启，内存摘要已清除。未记录原始操作人或私聊标识。

## 剩余工作

需要核实 QQ 官方对入群操作人、私聊身份和权限的语义与账号适用范围；实现用户会话绑定的一次性验证码、身份校验、有效期和重放防护；处理已有群认领、冲突、机器人退出、权限撤销和恢复。不能将群号、自称管理员或测试布尔结果作为授权依据。需要自动化及多账号真实联调后再上线授权。

`identity_probe.py` 仅为临时诊断，不是正式授权程序；本地测试可用 `python -m unittest discover -s . -p 'test*.py' -v`。
