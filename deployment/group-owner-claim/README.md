# 群管理员自主认领：能力验证阶段

目标：群主或管理员将 QQ 官方机器人添加到新群后，可以在群忆认领该群；无需网站总管理员。当前没有开启或实现自动授权。

线上机器人在 `GROUP_ADD_ROBOT` 处理分支增加了仅显示布尔值的诊断日志，用于检查未来事件中是否带有操作人标识。该诊断不保存、输出或绑定操作人标识，不凭群号、网站用户名或事件时间授权。现有已入群历史不含操作人信息，无法由此恢复身份。

已知未完成：QQ 身份与网站账号通过官方可用方式的可靠绑定；确认添加机器人者确有管理身份；事件重放、群认领冲突、权限移除、历史群恢复方案；完整端到端测试。诊断结果为真只能说明事件带有字段，不能证明身份绑定或群角色。

测试：`python -m unittest discover -s . -p 'test*.py' -v`。本地测试覆盖诊断逻辑，尚未使用真实新群验证。
