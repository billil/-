# 群认领身份绑定原型

截至 2026-11-05，线上群管理页展示“群主接入我的群”禁用状态，`claim_http.py` 状态接口需要登录且永不授予权限。其余功能仅为隔离原型，尚未接入真实机器人或开放网页认领。

## 真实接口检查

使用当前机器人、现有群消息中的群成员标识进行一次只读成员详情请求，QQ 返回 HTTP 400、错误码 11253，未得到角色。该结果需要在机器人开发者后台进一步确认具体权限与申请方式。没有 QQ 可靠身份核验与角色校验时不授予权限。

## 原型

已认证账号生成有效期 10 分钟的一次性验证码；仅由已认证机器人事件接收端记录机器人入群事件和私聊发送者；服务器比较摘要；只在唯一、非过期、顺序正确且未消费的事件存在时标记 identity_observed。任何状态都明确 `admin_granted: false`。单次观察到入群与私聊标识相同不能当作平台级保证。

`qq_role_verifier.py` 只有在QQ接口返回同一成员且明确角色时才返回角色；接口错误、角色缺失、标识不符均失败。`claim_http.py` 是默认禁用的状态入口，`claim-panel.js` 是未接入的UI样例。

上线前须验证平台身份语义、群角色、事件认证、码限流、事务、密钥管理、周期清理、已有群认领、管理员冲突、机器人移出和撤权；任何公开 API 不得接受客户端伪造的机器人事件或角色结论。

本地测试：`python -m unittest discover -s . -p 'test*.py' -v`，16 项通过；真实网页端到端尚未验证。
