# 群认领身份绑定原型

截至 2026-11-05，线上群管理页展示“群主接入我的群”禁用状态，`claim_http.py` 状态接口需要登录且永不授予权限。其余功能仅为隔离原型，尚未接入真实机器人或开放网页认领。

## 已验证的QQ平台限制

使用现有机器人及现有群消息中的群成员标识进行一次只读成员详情请求，QQ 返回 HTTP 400、错误码 11253，未得到角色。该机器人后台显示主体未认证，并提示此状态仅管理员使用、只能添加到管理员作为群主的群；个人认证后可以设置公开使用。群管理权限配置列出进群申请审批、发言管理等，未发现群成员身份查询的自助开关；这不证明平台绝无申请方式或认证后一定开通该接口。

需要用户在平台自行完成主体注册/认证及协议操作。无可靠身份核验与角色校验时不得授予管理员权限。

## 原型

已认证账号生成有效期10分钟的一次性验证码；仅由已认证机器人事件接收端记录机器人入群事件和私聊发送者；服务器比较摘要；只在唯一、非过期、顺序正确且未消费的事件存在时标记 identity_observed。任何状态都明确 admin_granted: false。单次观察到入群与私聊标识相同不能当作平台级保证。

qq_role_verifier.py 在接口返回同一成员且明确角色时才返回角色；错误、角色缺失、标识不符均失败。claim_http.py 是已上线且默认禁用的状态入口。claim-panel.js 是未接入的UI样例。上线前须验证平台身份语义、群角色、事件认证、验证码限流、事务、密钥管理、周期清理、已有群认领、管理员冲突、机器人移出和撤权；任何公开API不得接受客户端伪造的机器人事件或角色结论。

测试：`python -m unittest discover -s . -p 'test*.py' -v`，16项通过；真实网页端到端尚未验证。
