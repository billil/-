# 群认领身份绑定原型（未上线）

该模块仅用于测试网站会话与机器人事件的绑定，不会创建群管理员、不接入真实机器人、不暴露网页接口。上线前必须确认官方文档与账号实际权限足以证明操作人为该群群主或管理员，并且 QQ 入群与私聊标识可可靠关联；单次一致不能作为授权规则。

原型：已认证账号生成有效期 10 分钟的一次性验证码；仅由已认证机器人事件接收端记录机器人入群事件和私聊发送者；服务器比较摘要；只在唯一、非过期、顺序正确且未消费的事件存在时标记 identity_observed。任何状态都明确 `admin_granted: false`。

服务器端须确保可信会话、可信QQ网关/事件验签、一次性码保密、限流、事务幂等、保密随机密钥、周期清理。任何公开 API 都不得直接调用内部事件记录方法。不能把网页自填群号、QQ号、自称身份或客户端的验证布尔值当作可信事件。已有群、管理员冲突、丢失管理权、退群和恢复需独立设计。

测试：`python -m unittest discover -s . -p 'test*.py' -v`。
