# 标签体验与 AI 建议：待联调草案

本目录是尚未部署的实现草案，不能覆盖线上文件直接上线。

- `ai_tags.py`：对已授权的单条消息调用模型，输出建议；不保存或自动应用标签。
- `main_bridge.py`：基于 group-access-staging 版本的示例接口，部署前必须与服务器当前文件逐行比较并合并。
- `ui_patch.py`：基于本次测试快照制作的前端补丁；需与线上完整代码核对。
- `search_result_renderer.js`：查找结果添加消息标签入口的草案。
- `test_ai_tags.py`、`test_bridge_tags.py`：模拟模型和身份权限测试。

标签保存在当前浏览器。用户点击 AI 建议时，所选消息的部分内容会发给已配置的外部模型。
