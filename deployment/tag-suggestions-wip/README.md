# 标签体验与 AI 建议

代码草案已用于 2026-11-05 的线上集成；此目录记录相关实现和测试，并非线上完整源码快照。后续部署前应与服务器当前版本比较，不能直接整体覆盖。

- `ai_tags.py`：对已授权的单条消息调用模型生成建议，不自动添加。
- `main_bridge.py`：建议接口及权限检查。
- `ui_patch.py`、`search_result_renderer.js`：前端集成草案，线上另有查找结果标签显示和缓存版本变更，尚未完整同步至此。
- 测试包含未登录、跨来源及无权限场景；已用模拟通知验证真实模型，尚待浏览器和手机端实际操作验证。

标签保存在当前浏览器。用户主动点击 AI 建议后，该条消息的部分内容会发给已配置的外部模型。
