## 当前版本说明

群忆已部署账号登录、授权群访问、智能查找、查询历史及标签建议相关功能。查询历史和标签保存在浏览器中，不自动跨设备同步；主动请求 AI 建议时，选中消息的一部分内容会发送给模型。

这些目录由已保存的开发分支和本地补丁整理而成，不是线上服务器的逐文件完整快照。线上最近的主前端、登录加载文件及智能查找标签显示有直接修改，尚未全部回收到仓库；不要直接覆盖线上部署。需在取得实际运行文件并完成脱敏、版本核对和真实浏览器联调后再作为部署基线。
