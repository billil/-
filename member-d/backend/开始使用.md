# 成员 D 开始使用

## 1 解压和启动

解压压缩包，进入 `qunyi-backend` 文件夹。该文件夹内应直接看见 `qunyi`、`tests` 和 `README.md`，不要进入更内层的 `qunyi` 再运行。

Windows PowerShell：

```powershell
py -3 --version
py -3 -m qunyi
```

如果电脑上只有 `python` 命令，将 `py -3` 改为 `python`。macOS/Linux 可用 `python3`。版本应为 3.10 或以上。没有额外依赖，不必先运行 pip。

终端出现 `mode=mock` 即为显式模拟模式。保持该终端运行。浏览器打开 `http://127.0.0.1:8000/health` 应看到 `ok: true`。其他无效路径返回 JSON 404 属正常行为，这不是缺少网页。

## 2 不依赖其他成员，完成演示

另开终端，进入相同目录：

```powershell
py -3 scripts/demo.py
```

脚本导入三条模拟消息，再导入一条有明确关联的地点更正；发起模糊查找、选择事件、读取原文、查询覆盖范围，最后查询一个不存在的事件。成功后生成 `demo-report.json`。示例通知中的日期是**模拟业务日期**，不是本次运行日期。

重复演示可能追加同内容更正。需要完全干净重演时：先按 Ctrl+C 停止服务，把当前 `state` 文件夹改名留作备份，再重新启动。不直接删除仍在使用的数据库。

## 3 自己验证后端

```powershell
py -3 -m unittest discover -s tests -v
py -3 scripts/verify_http.py
```

第二条命令使用临时目录和独立服务进程，在随机本地端口测试 HTTP、备份和恢复，不会改动你的 `state`。43 项测试为后端功能与边界验证，不等于用户调研、60 道真实需求评测或真实大模型准确率。

## 4 独立调试接口

下面在 PowerShell 中读取本机令牌，并查询数据。不要把读取的令牌粘贴到群里、前端源码或提交包。

```powershell
$credentials = Get-Content state/credentials.json -Raw | ConvertFrom-Json
$qunyiToken = $credentials.PSObject.Properties.Name | Select-Object -First 1
$qunyiHeaders = @{ Authorization = "Bearer $qunyiToken" }
Invoke-RestMethod http://127.0.0.1:8000/v1/coverage -Headers $qunyiHeaders
$qunyiBody = @{ question = "志愿活动" } | ConvertTo-Json
Invoke-RestMethod http://127.0.0.1:8000/v1/query -Method Post -Headers $qunyiHeaders -ContentType "application/json; charset=utf-8" -Body ([System.Text.Encoding]::UTF8.GetBytes($qunyiBody))
```

前端以后可通过同源代理接入。本服务不启用允许任意网站访问的 CORS，也不把令牌放 URL 参数；完整接口见 `docs/API.md`。

## 5 接真实模型时需要什么

需要组委会允许的服务地址、模型名称、后端凭据和协议说明。当前适配器只支持 `chat-completions` 风格 JSON：请求包含 `model`、`messages`、`temperature`，响应中的 `choices[0].message.content` 必须为 JSON 字符串。它不是中国移动或 WorkBuddy 的官方专用 SDK；若实际协议不同，替换 `qunyi/providers.py`，继续遵守同一结构化工具约定。

停服务后在本机终端设置：

```powershell
$env:QUNYI_MODE = "live"
$env:QUNYI_MODEL_URL = "https://实际允许的域名/完整调用路径"
$env:QUNYI_MODEL = "实际模型标识"
# QUNYI_API_KEY 通过你自己的本地凭据管理方式设置，不写进项目文件。
py -3 -m qunyi
```

这些是填写位置，不是可直接使用的真实参数。live 缺配置返回 503，模型超时返回 504，模型 HTTP/格式/证据问题返回 502，不会切换 mock。真实模式会把问题、当前条件和授权范围内的候选通知发给配置的服务；试验时优先使用模拟或授权脱敏数据。
