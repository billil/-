## 可复现方法

在项目根目录运行：

```bash
python scripts/run_tests.py
python scripts/verify_http.py
```

前者重新生成测试报告；后者使用随机本地端口和临时数据目录，生成 HTTP 报告。它们不需要真实密钥。原型没有完整前端，不执行私人群采集，不写入外部应用。
